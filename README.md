# Just Point Car — демо-сайт детейлинг-студии

Статичный одностраничник: `index.html` + `img/`. Запуск — `python3 -m http.server 4178` из этой папки, открыть http://127.0.0.1:4178.

Структура страницы повторяет структуру сайта karsondetailing.ru (по просьбе владельца), содержание — своё, по данным Just Point Car. Первый экран оставлен прежний (вариант v3: сравнение «до / после» на Mercedes GLC 300, четыре наклонных панели услуг).

## Источники данных

Проверено 28 сентября 2026 года.

- [Яндекс Карты](https://yandex.ru/maps/org/just_point_car/222922385914/): рейтинг 5,0, 56 оценок, 52 отзыва (все пятизвёздочные), награда «Хорошее место 2026», Москва, ул. Талалихина, 41, стр. 41, ежедневно 10:00–22:00, +7 985 274-45-10. Особенности карточки: оплата картой и наличными, парковка, Wi-Fi, предварительная запись, подарочный сертификат, тонирование, антигравийная плёнка, ремонт кожи, предпродажная подготовка.
- Оценки по темам оттуда же: мойка 100 % (34 отзыва), персонал 100 % (34), полировка 100 % (23), время ожидания 100 % (17), ремонт 100 % (10).
- Прайс в карточке помечен «Давно не обновлялось», поэтому цены на сайте не публикуются — это прямо сказано в разделе `#ceny`.
- Канал [@JPCDetailing](https://t.me/JPCDetailing): 177 постов, ноябрь 2024 — сентябрь 2026. Из них взяты марки плёнки и толщины (посты 89, 395, 420), список работ и фотографии.
- Запись — [@Justpointcar](https://t.me/Justpointcar), дублирующий канал в MAX.
- Отзывы в блоках приведены дословно с Яндекс Карт, сокращения помечены многоточием.

Расхождение по адресу: в описании Telegram-канала указано «41, стр. 40», в карточке Яндекса — «41, стр. 41». На сайте стоит адрес из карточки, расхождение отмечено в разделе контактов.

## История файлов

- `index.before-full-site.html` — версия только с первым экраном (25 сентября 2026).
- `index.before-wrap-hero.html` — версия до разворота первого экрана к оклейке.
- `src/index-v1.html`, `src/index-v2.html` — ранние варианты первого экрана.
- `src/variant-jpc-demo/` — самый первый прототип первого экрана со своим README.

Демо, не официальный сайт студии. В `<head>` стоит `noindex, nofollow`.
