# Подготовка к размещению после 24 ноября 2026

Пакет является сборкой для предварительной проверки. Утверждённый первый экран сохранён.
Домен ещё не куплен. Индексация закрыта; реальные заявки не подключены.

## Что находится в архиве

- public/ — только эти файлы загружаются в корень сайта.
- setup/ — инструкции и пустой образец секретов; хранить вне публичной папки.
- MANIFEST.json — SHA-256 файлов для проверки целостности.

## Сборка после покупки домена

Из папки проекта выполнить:

```sh
python3 deploy/build_release.py --domain ВАШ-ДОМЕН.ru
```

Команда создаст новый архив в release/. Она подставит HTTPS-адрес в canonical,
Open Graph, Twitter, JSON-LD и sitemap. Исходники и прежние архивы не перезаписываются.
Без --domain создаётся подготовительный архив с текущим демонстрационным адресом.
Сборка намеренно не включает индексацию автоматически.

## Порядок запуска

1. Сделать резервную копию файлов хостинга, если на нём уже есть сайт.
2. Включить PHP 8.3 или 8.4, cURL, mbstring и HTTPS для домена.
3. Загрузить содержимое public/, проверить первый экран и контакты.
4. Разместить секреты выше корня сайта по REG-RU.md; права файла 600,
   чтение должно быть доступно процессу PHP. Проверить, что URL с секретами не открывается.
5. Добавить согласованные документы и ссылки на них из обеих форм.
6. Отправить по тестовой заявке из каждой формы. Подтвердить получение только в рабочем Telegram.
   Проверить пустые поля, ошибочный телефон, отсутствие согласия и повторную отправку.
7. Проверить поведение при недоступном Telegram: введённые данные сохраняются,
   успешная отправка не показывается.
8. После проверки убрать демо-абзац в подвале и meta robots noindex,
   в robots.txt заменить Disallow: / на Allow: / и указать Sitemap с купленным доменом.
9. Подключить счётчик Метрики и цели: успешная заявка, Telegram, телефон.
   Номер счётчика пока не задан. Добавить домен в Вебмастер и карточку Яндекс Бизнеса.
10. Проверить с телефона HTTPS, карту, контакты, загрузку фотографий и обе формы.

## Границы текущей проверки

Дублирование на justpointcar@yandex.ru запланировано. Для реализации нужна настройка почтового отправителя на хостинге. В текущем обработчике email-отправки ещё нет.

Браузерные тесты используют тестовые ответы сервера. Они проверяют интерфейс,
но сами по себе не подтверждают доставку в Telegram.
Проверка на реальном REG.RU и подтверждение доставки выполняются после покупки хостинга.
GitHub Pages используется для демонстрации: формы на этом адресе ничего не отправляют. Регистрация домена и перенос на REG.RU выполняются отдельно.
