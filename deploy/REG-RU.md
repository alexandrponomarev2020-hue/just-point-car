# Размещение Just Point Car на REG.RU

## 1. Тариф

Нужен Hosting Linux с поддержкой PHP. Для домена включить PHP 8.3 или 8.4 с cURL и mbstring; поддержку выбранного тарифа проверить при покупке.

## 2. Telegram-бот

1. Бот @JustPointCarLeadsBot уже создан Даниилом; токен хранится отдельно от проекта.
2. Единственный получатель заявок — аккаунт @Danyaa73, по последнему подтверждению Даниила.
3. Даниил сообщил о нажатии Start с этого аккаунта. Проверить это через getUpdates перед подключением.
4. Получить один числовой chat ID аккаунта @Danyaa73. Токен передавать серверным инструментом; не вставлять его в адрес браузера, чтобы он не остался в истории.

Бот не может писать произвольному личному `@username`, поэтому нужны именно chat ID и предварительный Start.

## 3. Секреты

1. Скопировать `deploy/jpc-secrets.example.php`.
2. Подставить токен и только один chat ID рабочего получателя. Конфигурация с несколькими получателями отклоняется.
3. Сохранить как `jpc-secrets.php` на один уровень выше корневой папки домена.
4. Не класть файл с реальным токеном в публичную папку домена или в Git.

Пример раскладки:

```text
…/www/
├── jpc-secrets.php
└── example.ru/          # корень сайта
    ├── index.html
    ├── api/
    │   └── lead.php
    └── img/
```

## 4. Загрузка и проверка

1. Распаковать сборку и загрузить только содержимое public/ в корень домена REG.RU. setup/, тесты, инструкции и секреты в публичную папку не загружать.
2. Открыть `https://домен/api/lead.php`: должен вернуться JSON с ошибкой `method_not_allowed` и HTTP 405.
3. Отправить тестовую заявку из каждой формы.
4. Убедиться, что заявка пришла только в рабочий Telegram.
5. Проверить неверно заполненную форму и повторную отправку раньше 20 секунд.

Перед открытием сайта выполнить оставшиеся пункты LAUNCH.md: документы для форм, окончательный домен, HTTPS и проверка доставки. Затем включить индексацию и убрать демо-плашку.

Копия на justpointcar@yandex.ru: запланирована, пока не реализована. Настроить отправителя и почтовую доставку на REG.RU; проверить входящие и папку «Спам».
